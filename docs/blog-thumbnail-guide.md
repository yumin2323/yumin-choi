# 블로그 썸네일 디자인 시스템

블로그 글 썸네일을 만들 때 따르는 규칙입니다. 구현은 `src/components/post-thumbnail.tsx` 한 파일에 있고, 이 문서의 규칙은 그 파일의 기존 썸네일 4개를 기준으로 정리했습니다.

## 방향

썸네일은 실제 제품 UI의 스크린샷이 아니라 **제품 UI를 추상화한 설명용 다이어그램**입니다.

- 글의 핵심 아이디어 하나를 도형의 배치와 강조로 보여 줍니다.
- 글마다 완전히 다른 그림을 만들기보다, 같은 UI 언어(노드, 패널, 입력 칸, 스켈레톤 막대, 연결선)를 조합합니다.
- 사이트 전체의 editorial 톤을 해치지 않도록 조용하게 그립니다. 목록에서 제목보다 먼저 튀지 않아야 합니다.

## 캔버스

| 항목 | 규칙 |
| --- | --- |
| 크기 | `viewBox="0 0 1200 630"` (1.91:1) 고정 |
| 모서리 | 캔버스 자체는 CSS로 `rounded-[10px]`. SVG 안에서 따로 그리지 않음 |
| 여백 | 그림 영역은 사방으로 캔버스의 **10~15%** 이상 띄움. gold 점의 테두리 정도는 살짝 넘어가도 됨 |
| 구성 | 중앙 또는 약간 좌우 비대칭. 시선이 처음 가는 곳(강조 요소)은 항상 하나 |

1.91:1은 링크 미리보기(Open Graph) 이미지의 표준 비율입니다. 나중에 썸네일을 `og:image`로 그대로 쓸 수 있도록 16:9 대신 이 비율을 씁니다.

## 색

색은 **직접 값을 쓰지 않고 `globals.css`의 변수만** 씁니다. 그래서 다크 모드로 바꾸면 썸네일도 따라서 바뀌고, 다크용 그림을 따로 만들 필요가 없습니다.

| 역할 | 변수 | 쓰는 곳 |
| --- | --- | --- |
| 배경 | `--soft` | 캔버스 전체. 모든 글이 같은 배경 |
| 평범한 면 | `--background` | 노드, 패널, 입력 칸의 안쪽 |
| 평범한 선·막대 | `--line` | 테두리, 연결선, 스켈레톤 막대 |
| 흐린 요소 | `--muted` (+ 투명도) | 강조하지 않는 텍스트 줄, 버려진 요소, 비활성 glyph |
| 메인 (navy) | `--accent` | 글의 핵심 아이디어 하나: 경로, 묶음, 바뀐 노드, 필요한 글자 |
| 메인 면 | `--accent-soft` | 강조된 노드·박스의 안쪽 |
| 포인트 (gold) | `--gold` | 강조 요소의 모서리에 찍는 작은 점 **하나** |

- 한 썸네일은 **navy 계열 + gray 계열 + gold 점** 세 계열로만 그립니다. `--accent`와 `--accent-soft`는 같은 navy 계열로 칩니다.
- 글마다 배경색을 바꾸지 않습니다. 모든 썸네일이 `--soft` 하나를 써야 목록에서 한 묶음으로 보입니다.
- 흐리게 만들 때는 `opacity` 대신 `fillOpacity`나 `strokeOpacity`를 씁니다. 글자(`<text>`)에 `opacity`를 걸면 다크 모드에서 글자 뒤에 네모난 자국이 생길 수 있습니다.

### gold 점

- 크기는 반지름 8~9, 둘레에 `stroke={soft}`, `strokeWidth={3}`으로 배경과 떨어뜨립니다.
- 위치는 강조 요소(마지막 노드, 바뀐 노드, 결과 패널, 필요한 glyph)의 오른쪽 위 모서리입니다.
- 선이나 면을 gold로 칠하지 않습니다.

## 선과 모양

SVG 안의 숫자는 **1200 폭 viewBox 기준 단위**입니다. 목록(680px)에서는 약 0.57배, 모바일(약 350px)에서는 약 0.3배로 줄어 보이므로, 실제 화면의 px로 정하지 않습니다.

| 항목 | 규칙 |
| --- | --- |
| 기본 stroke | 2 |
| 촘촘한 배경 요소 | 1.5 (그래프의 엣지와 평범한 노드처럼 요소가 많을 때) |
| 강조 stroke | 2.5~3 (`--accent`) |
| 흐름을 나타내는 연결선 | 강조 stroke + `strokeDasharray="2 9"` + `strokeLinecap="round"` (점선) |
| 선 끝 | `strokeLinecap="round"`, 꺾이는 곳은 `strokeLinejoin="round"` |
| 큰 패널·박스 | `rx` 12~16 |
| 작은 노드·입력 칸 | `rx` 8 |
| 스켈레톤 막대 | 높이 12~16, `rx`는 높이의 절반 (알약 모양) |
| 그림자 | 쓰지 않음 |
| 그라디언트 | 쓰지 않음 |

## 글자

- 제목, 설명, 숫자, 라벨 같은 글자는 넣지 않습니다. 글의 내용은 썸네일 아래 제목이 말합니다.
- 텍스트가 있어야 할 자리는 스켈레톤 막대로 대신합니다.
- 예외적으로 주제 자체를 보여 주는 기호나 glyph(`Aa`, `가`, `あ`, `{}`, `[]`, `</>` 등)는 쓸 수 있습니다. 이때 글꼴은 `style={{ fontFamily: "var(--font-sans)" }}`, 굵기는 600으로 사이트 글꼴을 따릅니다.

## 구성

- **메인 모티프 1개 + 보조 요소 1~2개**
  - 예: 메인 = 워크플로우 노드 줄, 보조 = 이벤트 타임라인, 둘을 잇는 점선 하나
- 강조(`--accent`)는 메인 모티프 안에서 **하나의 아이디어**에만 씁니다. 경로 하나, 묶음 하나, 노드 하나처럼요.
- 나머지는 모두 gray 계열로 두어서, 강조가 없는 상태의 그림도 차분해야 합니다.
- 전·후 비교처럼 수치가 핵심인 글은 막대 길이를 실제 비율대로 그립니다. 예: 폰트 글의 2.06MB 대 53KB.

## 글 종류별 모티프

필수는 아니고, 새 글의 그림을 정할 때 출발점으로 씁니다.

| 글 종류 | 모티프 | 강조할 것 |
| --- | --- | --- |
| 성능·최적화 | 경로, 병목, 흐름 | 개선된 경로나 병목 지점 |
| 상태 관리·실시간(SSE) | 이벤트 스트림, 큐, 묶음 | 한 번에 반영되는 묶음, 바뀐 요소 하나 |
| 폼·스키마 | 트리, 필드, 입력 블록 | 스키마에서 폼으로 이어지는 필드 |
| 그래프 | 노드와 엣지 | 경로 하나 |
| 폰트 | glyph 칸 | 실제로 필요한 glyph |
| 데이터·차트 | 표 + 간단한 시각화 | 선택된 셀 범위나 막대 하나 |
| 배포·운영 | pipeline, 단계 | 지금 단계나 바뀐 단계 |
| 디자인 시스템 | 컴포넌트 블록, 토큰 | 토큰에서 컴포넌트로 이어지는 흐름 |

## 새 썸네일 추가하기

1. `src/components/post-thumbnail.tsx`에 그림 함수를 하나 만듭니다. 함수는 `<g>` 하나를 돌려주고, 배경(`--soft`)은 공통 컴포넌트가 그리므로 넣지 않습니다.
2. 같은 파일의 `thumbnails`에 글의 slug를 키로 등록합니다. `label`에는 그림을 설명하는 한 문장을 적습니다. 스크린 리더가 읽는 대체 텍스트입니다.
3. 좌표는 배열로 정하고 반복문으로 그립니다. 노드 위치를 바꿀 때 연결선이 함께 따라오게 하기 위해서입니다.
4. 등록하지 않은 글은 목록에서 그림 없이 제목만 보입니다.
